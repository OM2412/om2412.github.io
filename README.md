## What's here

- Four source-linked projects with explicit collaborator credits and prototype boundaries.
- Expandable engineering notes and project filters.
- Dark/light themes, keyboard navigation and reduced-motion support.
- A client brief helper that opens an email draft. It sends and stores nothing on this site.
- No package dependencies, analytics, backend or paid API.

## Preview locally

```sh
python3 -m http.server 8090
```

Open http://localhost:8090. On Windows, `py -m http.server 8090` works when Python is installed.

## Deploy

GitHub repository **Settings → Pages → Deploy from a branch → main → / (root)**. The `.nojekyll` file enables direct static-file publishing. No custom domain is required.

## Update content

- `index.html`: project copy, collaborator credits, links, contact address.
- `styles.css`: responsive layouts and both themes.
- `script.js`: filters, optional theme preference, email-copy and draft helper.
- `assets/`: portrait, actual ReturnTrail project capture and original SVG branding.

If changing the contact email, update both `index.html` and `script.js`.
